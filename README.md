# 데이터이음 · 운영 코드 스냅샷

공공데이터를 검색하고 관련 주제로 탐색한 뒤, 제공기관 원문으로 이동하도록 돕는 서비스입니다.

## 이 저장소의 범위

2026년 10월 6일 운영 중인 Docker 컨테이너에서 추출한 코드 사본입니다. **공개·추출 날짜는 최초 개발일이나 전체 개발기간을 뜻하지 않습니다.** 대회 이전의 검색·카탈로그·연결 지도 기반과 이후 개발·개선 내용이 함께 포함되어 있습니다.

기존 Git 작업 이력은 이 배포 사본에 포함되어 있지 않습니다. 소스에 남아 있는 버전 식별자·날짜·출처·저작권 표기는 변경하지 않았습니다. 원래 저장소와 개발 기록도 삭제하거나 다시 작성하지 않았습니다.

## 코드 구성

| 경로 | 내용 |
| --- | --- |
| `discovery_harness/` | 검색 실행·조건 검토·상태 관리·API·주제 탐색 구현 |
| `discovery_harness/web/` | 정적 웹 화면·스크립트·스타일 |
| `experiments/` | AI 검색·LangGraph 워크플로 |
| `catalog.py`, `collectors.py`, `registry.py` 등 | 수집·카탈로그·분류·임베딩 처리 |
| `operations/` | 배포·유지관리·데이터 처리 코드. 사용 전에 환경·설정을 확인해야 하는 운영 스크립트 포함 |
| `frontend/` | Docker에 들어 있는 웹 프런트엔드 **빌드 결과물**. 원래 React/TypeScript 프로젝트 소스는 해당 이미지에 포함되어 있지 않음 |
| `requirements.txt` | 이미지에 포함된 의존성 목록. 전체 실행환경을 단독으로 재구성하는 잠금 파일은 아님 |
| `SOURCE_MANIFEST.json` | 추출 기준 이미지·시각, 파일별 서비스 출처 및 원본·공개본 SHA-256 |
| `PUBLIC_EXPORT_NOTES.md` | 공개 사본에서 접속정보·개인 경로를 정리한 내역 |

API·웹 자산은 Atlas, AI 실행은 Luna, 벡터 검색은 Vector의 실제 담당 구현을 기준으로 통합했습니다. 서비스별 중복 사본 중 일부 웹 자산이 다른 경우 실제 웹을 제공하는 Atlas의 파일을 사용했습니다.

## 포함하지 않은 항목

- 인증정보, API 키, 비밀번호, `.env`, 계정·세션 파일
- 운영 데이터베이스, 임베딩·검색 색인, 백업, 실행 로그
- 실제 문의 수신처 설정과 운영 환경 설정

이 사본은 코드 열람을 위한 자료입니다. 전체 서비스 실행에는 외부 모델 접근·인증, 메타데이터 저장소, 검색 색인 및 별도 배포 설정이 필요합니다. 모든 기능이 이 ZIP 또는 저장소만으로 실행된다는 의미는 아닙니다.

## 기능 상태

- 자료 검색·관련 주제 탐색·원문 안내: 운영 확인 범위
- 메일 관련 구현: 소스에 포함되어 있으나 실제 발송은 비활성
- 원자료 오류·누락·품질 검사(QA): 향후 확장 계획이며 현재 완료 기능으로 주장하지 않음

## 출처와 라이선스

자체 서비스 코드와 타사 모델·라이브러리 사용 부분을 구분합니다. LangGraph, FAISS, FastAPI, NumPy, HTTPX 등은 각 프로젝트의 라이선스를 따릅니다. 프런트엔드 빌드 결과물에 포함된 React·React DOM·Scheduler의 버전과 MIT 고지 전문은 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)에 기재했습니다. 공개데이터의 이용조건은 각 제공기관 원문을 따릅니다. 코드 공개만으로 연결된 원자료의 재배포 권한을 부여하지 않습니다.

이 공개 사본에 대해 새로운 오픈소스 라이선스를 임의로 지정하지 않았습니다.
